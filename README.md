# Fradzkhan Ulao — Senior Full-Stack & AI Engineer Portfolio

A recruiter-focused portfolio website that preserves the original Fradzkhan / DEV visual language while updating the content for Senior Full-Stack & AI Engineer job applications.

## Highlights

- Original dark navy / aqua portfolio design
- Senior Full-Stack & AI Engineer positioning
- Full-stack + AI balanced professional experience
- 8 GitHub-backed portfolio projects
- AI, full-stack, cloud and DevOps skill areas
- LinkedIn, GitHub and email contact links
- Responsive design for desktop, tablet and mobile
- No third-party UI dependencies

## Run locally

```bash
npm install
npm run dev
```

Open:

```text
http://localhost:3000
```

## Production build

```bash
npm run build
npm start
```

## Deploy to Vercel

1. Push this folder to GitHub.
2. Import the repository into Vercel.
3. Vercel should automatically detect Next.js.
4. Keep the default framework/build settings and deploy.
